# Calculus

## Overview
Calculus forms the mathematical foundation for optimization algorithms and understanding how models learn from data.

## Subdirectories

### 1. Differentiation
- Limits and continuity
- Derivatives and differentiation rules
- Applications in ML (gradient computation)

### 2. Integration
- Definite and indefinite integrals
- Integration techniques
- Applications in probability

### 3. Optimization
- Finding maxima and minima
- Critical points
- Optimization algorithms
- Applications in ML (training models)

## Importance in Machine Learning

Calculus is fundamental to:
- **Gradient Descent**: Computing gradients of loss functions
- **Backpropagation**: Computing derivatives in neural networks
- **Optimization**: Finding optimal model parameters
- **Understanding Convergence**: Analyzing algorithm behavior

## Files Structure

Each subdirectory contains:
- `README.md` - Specific topic overview
- `notes.md` - Detailed theory and formulas
- `examples.py` - Python implementations
- `applications.md` - ML applications and use cases
