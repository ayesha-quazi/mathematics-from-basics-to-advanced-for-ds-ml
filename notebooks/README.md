# Jupyter Notebooks

## Overview
This directory contains interactive Jupyter notebooks that provide hands-on examples, visualizations, and practical implementations of mathematical concepts covered in this repository.

## Notebooks by Topic

### Algebra and Functions
- `01_algebra_basics.ipynb` - Interactive examples of algebraic operations
- `02_functions_visualization.ipynb` - Graphing and visualizing functions

### Calculus
- `03_differentiation.ipynb` - Computing derivatives with SymPy and NumPy
- `04_integration.ipynb` - Numerical integration methods
- `05_optimization.ipynb` - Optimization techniques and visualizations

### Linear Algebra
- `06_vectors_matrices.ipynb` - Vector and matrix operations
- `07_matrix_decomposition.ipynb` - LU, QR, SVD decompositions
- `08_pca_tutorial.ipynb` - Principal Component Analysis step-by-step

### Probability and Statistics
- `09_probability_distributions.ipynb` - Working with distributions
- `10_statistical_inference.ipynb` - Hypothesis testing and confidence intervals
- `11_bayesian_methods.ipynb` - Bayesian inference examples

### Advanced Topics
- `12_eigenvalues_svd.ipynb` - Eigendecomposition and SVD applications
- `13_gradient_descent.ipynb` - Implementing and comparing optimizers
- `14_fourier_transform.ipynb` - Signal processing with FFT

### Machine Learning Applications
- `15_linear_regression_math.ipynb` - Mathematical foundation of linear regression
- `16_neural_network_math.ipynb` - Mathematics behind neural networks
- `17_feature_engineering_math.ipynb` - Mathematical transformations for features

## How to Use

1. **Install dependencies**:
   ```bash
   pip install -r ../requirements.txt
   ```

2. **Launch Jupyter**:
   ```bash
   jupyter notebook
   ```

3. **Open any notebook** and run cells sequentially

## Tips for Learning
- Run each cell and observe the output
- Modify parameters to see how results change
- Complete the exercises at the end of each notebook
- Experiment with your own examples

## Interactive Features
Many notebooks include:
- Interactive plots with Plotly
- Widgets for parameter tuning
- Step-by-step animations
- Real-world datasets
